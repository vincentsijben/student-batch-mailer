Student Batch Mailer

Match feedback files to students and send them through Outlook in one go.

How does matching work?

A file is matched to a student when every word of the student's first and last name appears somewhere in the file name (case-insensitive, any order). Example: Jo + Bonten, van de matches rubric-jo-van-de-bonten.pdf.

Accents and punctuation are ignored (José Müller matches jose-muller.pdf and jose-mueller.pdf).

If a student has both a PDF and a Word version, only the PDF is sent. Word files are never sent unless you explicitly choose to.

The message template is chosen automatically from the file names (e.g. rubric_MMT1_….pdf → template Rubric MMT1). Abbreviations work too: WS, MMT, VD, DR, PH. Hover over a template to see which words it reacts to.

Your original files are never changed or deleted: the app works with copies, which are removed when you remove a file from the list and when you quit the app.

The app never guesses. If a file fits more than one student, or a student fits more than one file, nothing is assigned and it shows up under Needs your attention in step 4, where you choose who gets what.

The roster needs three columns: firstname, lastname, email (Dutch voornaam, achternaam, e-mail also work). An optional studentid / studentnummer column can be used as {{studentid}}.
