Student Batch Mailer

Match feedback files to students and send them through Outlook in one go.

How does matching work?

A file is matched to a student when every word of the student's first and last name appears somewhere in the file name (case-insensitive, any order). Example: Jo + Bonten, van de matches rubric-jo-van-de-bonten.pdf.

Each file can be matched to one student only. If two files fit the same student, the first one wins — remove the wrong one with the × next to it.

The roster needs three columns: firstname, lastname, email (Dutch voornaam, achternaam, email also work).
